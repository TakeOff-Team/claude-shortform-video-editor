# my-style/

Your style lives here. It's empty until your first `/edit-video`, when Claude onboards you and writes:

- `style.md`: your style guide in plain words (edit it any time)
- `style.json`: the same style as settings the renderer reads
- `feedback.md`: every note you give, so you never repeat yourself
- `references/`: the videos you love, broken down frame by frame
- `music/`: your music bed, if you use one

It's ignored by git, so it stays yours even if you update the editor with `git pull`.
